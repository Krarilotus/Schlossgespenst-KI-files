# Schlossgespenst AI

本模组提供十二个全新的 AI，为遭遇战增添变化；每个角色都有自己的性格和风格。

### 新角色与熟悉的角色

包括对*圣女贞德*、*Guilhabert de Castres*和*基利杰·阿尔斯兰一世*等**历史人物的演绎**，*伍尔萨克领主*和*Schlossgespenst*等**熟悉角色**，以及*强盗*、*恶魔*等**新角色**。其强度大致从毒蛇到略强于野狼（Fixed Vanilla）。

![Schlossgespenst](https://raw.githubusercontent.com/Schlossgespensty/Content/refs/heads/main/Schlossgespenst-KI-preview/Schlossgespenst-KI-preview-en.png)

每个 AI 最多四座新城堡及其战略和性格均由我构思并制作。肖像、视频和语音由其他游戏片段、图片等素材组合而成。文本和字幕提供英语翻译，但所有语音文件均为德语。
